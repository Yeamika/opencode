Apply a REC line patch to one recently read file.

Inputs:
- `filePath`: use the file reference returned by the read tool, for example `App.ts #A1B2`.
- `patchText`: REC line patch text. Do not use the old `*** Begin Patch` envelope.

REC line patch syntax uses original 1-based line numbers:
- `replace A B` replaces original lines A through B.
- `delete A B` deletes original lines A through B.
- `insert N` inserts after original line N; `insert 0` inserts at the start; `insert -1` inserts at the end.
- Body lines are `+text` for literal new text, or `copy A B` to reuse original lines.

Example:
```
replace 11 11
+new line
```

The target file must have been read in this session. OpenCode resolves the `filename #ABCD` reference to the original executor and file, passes REC the full hash for stale-write protection, and returns a new `filename #WXYZ` reference after a successful patch.
